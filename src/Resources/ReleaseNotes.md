## Release v1.2.0

- 저장소마다 연결 프로그램을 선택하고 상단의 작은 버튼으로 프로젝트를 열 수 있습니다. 설치된 IDE 또는 실행 파일을 직접 선택하고, 열 폴더·솔루션·워크스페이스도 지정할 수 있습니다.
- Unity는 현재 저장소 자체가 Unity 프로젝트일 때만 표시하고 프로젝트에 맞는 설치 버전으로 엽니다. 서버 아래 Client가 Unity 프로젝트라는 이유로 서버에 Unity 실행 버튼이 나타나던 문제를 해결했습니다.
- Windows에서는 연결 프로그램의 실행 파일에서 실제 앱 아이콘을 읽어 표시합니다. 연결 프로그램용 로고 이미지는 내장하지 않으며 아이콘을 읽지 못하면 공통 열기 아이콘을 사용합니다. 앱 정보에 크레딧을 추가했습니다.
- 커밋 검색을 Ctrl+F(macOS는 Cmd+F) 한 줄 검색으로 통일했습니다. 기존 큰 검색 패널과 Ctrl+Shift+F는 제거하고, 검색 결과를 기존 커밋 목록과 그래프에 바로 표시합니다.
- 커밋 메시지·본문, 해시, 작성자·이메일, 파일 경로와 변경 내용으로 검색할 수 있습니다. 현재 브랜치로 범위를 좁힐 수 있고 Esc 또는 닫기를 누르면 원래 목록으로 돌아옵니다.
- 연결 프로그램 선택을 저장소별로 기억하며 워크트리마다 자신의 프로젝트 경로를 엽니다. 처음 선택한 설정이 저장되지 않을 수 있던 문제도 해결했습니다.
