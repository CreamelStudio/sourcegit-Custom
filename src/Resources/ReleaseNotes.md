## Release v1.1.0

- 환경설정 → 프리셋에서 열린 탭·순서·선택과 테마·글꼴·배율·패널 배치를 10개 슬롯에 저장할 수 있습니다.
- Ctrl+F1~F10으로 프리셋을 전환하고, Ctrl+Shift+F1~F10으로 현재 구성을 해당 슬롯에 빠르게 저장합니다. 다시 저장하면 해당 슬롯의 저장본을 덮어씁니다.
- 하단 Fetch 상태 앞에 현재 프리셋 번호와 이름을 작게 표시합니다. 클릭하면 프리셋 전환·현재 구성 저장·설정 메뉴가 열립니다. 긴 이름은 줄여 표시하고 툴팁에서 확인할 수 있습니다.
- 탭 구성이나 화면 설정이 저장본과 달라지면 작은 점을 표시합니다. 평소 탭 선택이나 저장소 화면 이동은 변경 표시를 켜지 않습니다. 다시 저장하거나 원래 구성으로 되돌리면 점이 사라집니다.
- 다른 폴더에 준비한 서버·Client 저장소도 프리셋으로 함께 전환할 수 있습니다. 프리셋은 Git 브랜치나 작업 파일을 바꾸지 않습니다.
- Unity 프로젝트를 감지하면 상단에 작은 열기 아이콘을 표시합니다. 저장소 자체와 준비된 Client·서브모듈을 지원하며, 여러 프로젝트가 있으면 선택할 수 있습니다.
- Unity 열기는 프로젝트에 기록된 버전과 일치하는 에디터를 Hub의 기본·지정 설치 폴더에서 찾습니다. 일치하는 에디터가 없으면 안내하며 다른 버전으로 자동 전환하지 않습니다.
