## Release v1.3.2

- 저장소를 열 때 커밋 조회와 화면 생성을 동시에 진행해 큰 저장소의 대기 시간을 줄였습니다.
- 브랜치 전환과 Pull·Fetch·Push가 끝나면 대기 중인 변경 알림을 바로 처리합니다. 외부 프로그램의 파일 편집에는 기존 대기 방식을 유지합니다.
- Windows의 서브모듈 상태 확인에서 불필요한 셸 실행을 줄였습니다. 지원하지 않는 Git에서는 기존 명령으로 다시 확인합니다.
- 브랜치의 앞선·뒤처진 커밋을 빠르게 찾도록 자료구조를 개선하고, 여러 브랜치의 상태 조회를 제한된 수로 병렬 처리합니다.
- 이전 조회의 취소를 하위 커밋 조회까지 전달해 불필요한 작업을 줄였습니다.
- 브랜치 전환·Pull 전의 복구 지점, 서브모듈 갱신, 변경 파일 보호와 실패·취소 처리는 유지합니다.
