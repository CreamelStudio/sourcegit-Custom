## Release v1.1.2

- 폴더를 지운 워크트리 때문에 브랜치 체크아웃·삭제·워크트리 생성이 막히는 문제를 해결했습니다. 저장소 목록 갱신과 작업 전에 안전하게 정리할 수 있는 오래된 등록을 자동으로 해제합니다.
- 실제 폴더가 남아 있거나 잠긴 워크트리, 연결되지 않은 드라이브·이동식 드라이브·네트워크 경로, 분리된 HEAD의 워크트리는 보존합니다. 정리 후보 중 안전성을 확인할 수 없는 항목이 있으면 자동 정리를 보류합니다.
- 자동 정리는 Git 등록 정보만 해제하며 브랜치와 현재 작업 파일을 유지합니다. 부모 저장소와 Client를 각각 열면 각 저장소의 오래된 워크트리 등록을 처리합니다.
