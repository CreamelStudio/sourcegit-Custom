## Release v1.1.1

- 상단의 작은 저장소 도구 버튼에서 복구 타임라인·저장소 묶음 검색·백그라운드 작업을 열 수 있습니다.
- 브랜치 전환·rebase·reset 등 주요 작업 전에 커밋 위치를 보존하고 Git 작업 기록과 함께 표시합니다. 원하는 지점에서 복구 브랜치를 만들 수 있으며 현재 브랜치와 파일은 바꾸지 않습니다. 미커밋·추적하지 않는 파일의 내용 백업은 포함하지 않습니다.
- 현재 프리셋 또는 작업공간의 저장소와 초기화된 서브모듈을 묶어 커밋 메시지·파일 이름·추적 중인 텍스트 내용을 검색합니다. 대상 저장소를 선택하거나 검색을 취소할 수 있고 결과에서 커밋·파일을 열 수 있습니다.
- 클론과 서브모듈 준비를 별도 백그라운드 프로세스가 처리합니다. 앱 창을 닫거나 업데이트해도 진행되며 다시 연 앱의 작업 목록에서 진행 상태·결과·취소를 확인할 수 있습니다.
- 환경설정 → Git의 '앱을 닫아도 자동 Fetch 계속하기'를 지원합니다. 자동 Fetch 사용 여부·주기·remote 제외 설정을 따르며, 작업 창에서 대상 저장소를 예약에서 제외할 수 있습니다.
- 자동 Fetch는 최대 4개, 클론은 최대 2개까지 진행합니다. 동일 Git 저장소를 공유하는 작업은 앱과 백그라운드 프로세스 사이에서도 겹치지 않도록 조정합니다.
- 백그라운드 프로세스는 기존 Git 인증을 사용합니다. 추가 로그인이 필요하면 실패 내역을 확인한 뒤 인증을 준비해주세요. 취소·실패·프로세스 중단으로 남은 클론 폴더는 자동 삭제하지 않습니다.
- 진행할 작업과 백그라운드 Fetch 예약이 없으면 작업 프로세스가 종료됩니다. 앱 버전이 바뀌면 진행 중 작업을 마친 뒤 새 작업 프로세스로 넘깁니다.
- 기존 2026 버전 → 1.0.0 → 최신 숫자 버전의 업데이트 경로와 1.1.0 배포 파일은 유지합니다.
